# Damp Neuro

AI чат с системой инвайтов и подпиской.

## Функции

- ✅ Регистрация/вход с инвайт кодами
- ✅ Админ панель для управления пользователями
- ✅ Система подписок
- ✅ Ban/Unban пользователей
- ✅ Отслеживание устройств

## Установка

```bash
npm install
node server.js
```

Сервер запустится на `http://localhost:3000`

## Админ аккаунт

- Username: `rocket`
- Используй инвайт код для регистрации

## Технологии

- Node.js + Express
- SQLite
- Vanilla JS
